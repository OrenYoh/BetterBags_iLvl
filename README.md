<h1 align="center">BetterBags - iLvl &bull; a BetterBags plugin</h1>
<p align="center"><img src="https://media.forgecdn.net/attachments/description/1014142/description_c5a558f2-ef7c-44fc-b14d-29461441c99d.png" alt="BetterBags - iLvl icon" width="300" height="300"></p>
<p align="center"><a href="https://www.curseforge.com/wow/addons/betterbags-ilvl" target="_blank" rel="nofollow noopener"><img src="https://img.shields.io/badge/CurseForge-BetterBags_iLvl-EB622B.svg?style=flat" alt="CurseForge BetterBags_iLvl"></a> <a href="https://addons.wago.io/addons/betterbags-ilvl" target="_blank" rel="nofollow noopener"><img src="https://img.shields.io/badge/Wago-BetterBags_iLvl-B71D23.svg?style=flat" alt="Wago BetterBags_iLvl"></a></p>
<p>Create a custom category to filter low iLvl items (the threshold can be set in the options) in BetterBags.</p>
<p>The threshold can either be manually set, or dynamic based on your character iLvl (option only available in retail).</p>
<p>All items having an ilvl lower than the threshold set in the options will be grouped in a "Low iLvl" category.</p>
<p>You can choose not to include junk items in this category (included by default).</p>
<p>It's compatible with:</p>
<ul>
<li><a href="https://www.curseforge.com/wow/addons/betterbags-legendary" target="_blank" rel="nofollow noopener"><img src="https://img.shields.io/badge/CurseForge-BetterBags_Legendary-EB622B.svg?style=flat" alt="CurseForge BetterBags_Legendary"></a> <a href="https://addons.wago.io/addons/betterbags-legendary" target="_blank" rel="nofollow noopener"><img src="https://img.shields.io/badge/Wago-BetterBags_Legendary-B71D23.svg?style=flat" alt="Wago BetterBags_Legendary"></a></li>
<li><a href="https://www.curseforge.com/wow/addons/betterbags-tabards" target="_blank" rel="nofollow noopener"><img src="https://img.shields.io/badge/CurseForge-BetterBags_Tabards-EB622B.svg?style=flat" alt="CurseForge BetterBags_Tabards"></a> <a href="https://addons.wago.io/addons/betterbags-tabards" target="_blank" rel="nofollow noopener"><img src="https://img.shields.io/badge/Wago-BetterBags_Tabards-B71D23.svg?style=flat" alt="Wago BetterBags_Tabards"></a></li>
</ul>
<p>Meaning that if those plugins are installed, items matching those two will not end up in the "Low iLvl" category.</p>
